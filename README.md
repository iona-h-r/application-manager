## 概要
応募者情報の登録・管理を行うサーバーレスWebアプリケーションです。
一般ユーザーはアカウント登録後に応募を行うことができ、応募時には管理者へメール通知が送信されます。

管理者は管理画面から応募者情報を検索・閲覧できます。

---

## 機能

本システムで実現できる業務機能は以下の通り。


### 1. ユーザー側でできること

- アカウントを作成し、サービスを利用開始できる
- 登録済みアカウントでログインできる
- 公開されている案件を閲覧できる
- 案件に対して応募フォームから応募できる
- 自分の応募状況を確認できる **（必要に応じて追加開発予定）**

### 2. 管理者側でできること

- 管理者アカウントでログインできる
- 応募対象となる案件を作成・公開できる
- 各応募の詳細情報を閲覧できる
- 応募状況をもとに選考判断を行える **（必要に応じて追加開発予定）**

### 3. システムとして提供されること（裏側の機能）

- ユーザーの認証・ログイン状態の管理
- 応募時に管理者へ自動通知を送信
